# Keepsake — Responsive Agency Landing Page (`landing-keepsake`)

Адаптивний односторінковий лендінг дизайн-агенції **Keepsake**, зверстаний за макетом із Figma для фреймів **Mobile (375px)**, **Tablet (768px)** та **Desktop (1280px)** з підтримкою респонсиву від `320px` до `1920px`.

## Демо

- **Live Demo (GitHub Pages):** `https://Valentinedarks.github.io/landing-keepsake/`

## Структура проєкту

```text
landing-keepsake/
├── index.html          # Семантична HTML5-розмітка сторінки
├── css/
│   ├── reset.css       # Скидання стандартних браузерних стилів
│   ├── variables.css   # Дизайн-токени (кольори, шрифти, відступи, розміри) у :root
│   └── style.css       # Mobile-first стилі та медіа-запити (768px, 1280px)
├── images/             # Оптимізовані зображення у форматі WebP
├── fonts/              # Директорія для локальних шрифтів WOFF2 (за потреби)
└── README.md           # Опис проєкту та технічних рішень
```

## Використані технології та архітектурні рішення

1. **Семантичний HTML5 та доступність (A11y):**
   - Використано теги `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<blockquote>`, `<footer>`, `<form>`.
   - Дотримано ієрархії заголовків (`<h1>` у секції Hero, `<h2>` для секцій, `<h3>` для карточок).
   - Усі інтерактивні елементи мають видимий `:focus-visible`, іконочні кнопки забезпечені `aria-label`, поля форм мають приховані `<label>` та зв'язок помилки через `aria-describedby`.
2. **Архітектура CSS без фреймворків:**
   - **Mobile-first підхід:** базові стилі написані під `375px` (від `320px`), далі використано медіа-запити `@media (min-width: 768px)` та `@media (min-width: 1280px)`.
   - **Дизайн-токени:** усі кольори, розміри шрифтів і відступи винесені у CSS-змінні `:root` (`css/variables.css`).
   - **Розкладка:** Flexbox для навігації, кнопок, послуг, статистики, логотипів клієнтів, журналу та футера; CSS Grid з `aspect-ratio` для сітки портфоліо (`1` колонка на Mobile, `2` на Tablet, `3` на Desktop).
3. **Інтерактивність без JavaScript (Pure CSS):**
   - **Мобільне випадаюче меню:** реалізовано через прихований чекбокс `#nav-toggle` і комбінатор `~`, зі зміною іконки бургера на хрестик.
   - **Фільтрація портфоліо та кнопка «Load more works»:** реалізовано через приховані радіокнопки (`input[type="radio"]`) та селектори `:checked ~ .works-grid .work-card[data-category="..."]`.
   - **Стани форми підписки:** `focus` (бірюзовий бордер), `error` (`:user-invalid` із кораловим бордером та повідомленням), `success` (через `:target` після валідної відправки форми з обов'язковим чекбоксом згоди).
4. **Продуктивність:**
   - Зображення у форматі `.webp` із явно заданими `width` та `height`, а також `loading="lazy"` для секцій нижче першого екрана.
   - Підключення Google Fonts (`Oswald`, `Open Sans`, `Dancing Script`) із параметром `display=swap`.
